    Web Exploitation Field Notes

    Start with a signal. Confirm it. Identify the parser. Then choose the payload.

    Manual reference for CTF challenges and labs. Payloads are ready to adapt in a browser, Burp Repeater, or a request editor. No generated solver is needed to follow the workflows. Availability of notes and tools during your event depends on its rules.

    Pick your starting point

    What you have / what you see Open this First question
    A new URL or source archive First 10 minutes Where does each input go?
    Exposed backups, Git files, debug traces Source / backup leaks Can source reveal the actual sink and flag location?
    Search, login, sorting, numeric ID SQL injection Can I change a query condition?
    Confirmed SQLi, unknown database Database fingerprinting Which engine actually executed the query?
    MySQL / MariaDB MySQL Current schema → tables → columns → data
    PostgreSQL PostgreSQL Current schema → catalog → text casts
    SQLite SQLite Read sqlite_schema and CREATE TABLE definitions
    Microsoft SQL Server SQL Server DB_NAME → sys.tables → sys.columns
    Oracle Oracle DUAL → USER_TABLES → USER_TAB_COLUMNS
    SQLi confirmed, no rows displayed Blind / error SQLi What reliable true/false signal exists?
    A greeting / preview evaluates expressions SSTI Server evaluation or browser rendering? Which engine?
    JSON login, MongoDB operators NoSQL injection Does the app accept an object where it expects a string?
    Input becomes HTML or JavaScript XSS Which exact browser context contains the input?
    Ping, convert, archive, DNS tools Command injection Shell string or direct argument list?
    Filename, download, language/include Traversal / LFI Can I read a known file outside the intended directory?
    URL fetcher, webhook, PDF generator SSRF Which request does the server itself make?
    XML, SOAP, SVG upload XXE Does the parser resolve entities?
    Upload form / attachment API File upload Accepted, stored, served, interpreted: which stages work?
    Object IDs, roles, reset links Auth / IDOR Does the server enforce ownership and workflow state?
    Three-part bearer token JWT What is verified, with which key and algorithm?
    Serialized cookie / import Deserialization Which format and which server-side classes?
    Deep object merge / JS config Prototype pollution Can input alter inherited properties?
    GraphQL endpoint GraphQL Schema, resolver authorization, hidden arguments
    Cookie-authenticated state changes CSRF / CORS Can another origin send or read this request?
    OAuth login / account linking OAuth Are callback, identity, state, and session bound correctly?
    Live socket messages WebSockets Which message changes state, and when is completion reported?
    Coupon, payment, repeated claim Business logic / races Which invariant should hold after two requests?
    Proxy, cache, suspicious framing HTTP / cache issues Do two HTTP components disagree?
    PHP loose checks, arrays, hashes PHP quirks Which types and PHP version participate in the check?
    Directory/XML query syntax LDAP / XPath What grammar and boolean oracle does the sink expose?
    Redirect / return URL Open redirect What hostname does the consuming parser actually use?
    Blocked words / changed payloads Encoding / filters What bytes reach the final parser?
    Need prepared Python helpers Reusable snippets Byte transforms, JWT, or a confirmed boolean oracle?

    The loop for every technique

    Baseline request
  → one small probe
  → matching negative control
  → repeat the difference
  → fingerprint the parser / engine
  → select the matching payload
  → enumerate actual names / paths
  → read the challenge result

    An error is a clue; repeatable controlled behavior is evidence. A 200 OK, accepted upload, or login redirect alone does not prove success.

    Payload notation

    Notation Meaning
    ctf.invalid Placeholder challenge host; replace it
    YOUR-LAB-HOST Your permitted callback host, if callbacks are part of the challenge
    users, flags, flag, /flag.txt Example names; enumerate actual names first
    -- - SQL line comment with a trailing space after the two dashes
    NULL,NULL,EXPR Example three-column UNION; adapt count, types, and reflected position
    1' ... -- - Complete example input for a single-quoted query value
    SELECT ... in an engine page Standalone query fragment; insert it into your confirmed injection
    %XX URL-encoded bytes; do not encode twice unless two decoding stages exist

    Many pages deliberately show raw payloads. In Burp’s decoded parameter editor, enter the raw payload; in an actual URL/form body, encode transport-sensitive characters. JSON, URL forms, HTML, and shell quoting are different layers. See encoding.
