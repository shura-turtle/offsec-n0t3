    Steganography field notes

    Inspect the container before guessing the hidden algorithm. A file can hold a message in metadata, trailing bytes, pixels, sound samples, document objects or text code points.

    These notes use tools already covered in the approved-tool reference. Optional Python packages are explicitly marked: Python being available does not mean Pillow, NumPy or Matplotlib is installed or allowed by your event.

    Pick the evidence you have

    Evidence / clue Read next First useful action
    Unknown artifact or misleading extension Triage Magic, metadata, strings, dimensions, embedded signatures
    Lossless image, “least significant” hint Image LSB and bit planes Identify actual image mode and test one channel
    PNG/JPEG with odd size or broken structure Image containers Parse chunks/markers; distinguish pixels from compressed coefficients
    Appended ZIP, archive inside image Archives and carving Establish offset and length, list entries before extraction
    WAV, repeating tones, strange noise Audio Channels/sample format, waveform, spectrogram, sample bits
    PDF, DOCX, presentation PDF and documents Visible text, metadata, attachments, XML/media members
    Invisible characters, odd spacing Text and Unicode Escaped code points and symbol counts
    Need reusable offline extraction tools Python snippets Download helpers and choose explicit extraction settings

    Ordered route

    Original file + hash
  → inspect metadata / strings / format
  → inspect visible content or listen at a comfortable level
  → identify a specific hidden channel
  → extract exact bytes to a new file
  → classify the extracted payload
  → decode / decompress only the indicated layer
  → verify full message, checksum or valid nested format

    Fast toolbox map

    Task Existing notes
    Metadata and thumbnails ExifTool
    Readable data and byte offsets strings, xxd
    Hex inspection / precise selection HxD
    Embedded format candidates binwalk
    PNG/BMP bitstream candidates zsteg
    QR / barcode ZBar
    PDF text / internals pdftotext, qpdf
    Decompression / custom extraction xz, Python
    Encodings / XOR / visual decode CyberChef

    Keep these distinctions clear

    • A ZIP signature is a candidate offset, not a validated archive.
    • A decoder finding a short printable word in random bits is not a confirmed message.
    • PNG compressed file bytes are not the image’s decoded pixel bytes.
    • JPEG coefficient hiding is different from PNG pixel-LSB hiding.
    • A visually hidden object may still be ordinary document text.
    • A QR may give a hint while a different layer contains the result.
